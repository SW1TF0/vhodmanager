# Вход мениджър / Vhodmanager

Website for **Вход мениджър** – a professional condominium manager that replaces the volunteer
*домоуправител* in Bulgarian buildings under the Condominium Management Act (ЗУЕС).

Bulgarian is the primary language (served at `/`), with a full English version at `/en/`.

## Quick start

```bash
npm install
npm start          # builds into dist/ and serves it at http://127.0.0.1:8080
npm test           # build + HTML validation + static checks + browser/accessibility tests
npm run placeholders   # lists company details that still need filling in
npm run build:offline  # build into dist/ so pages open straight from disk (double-click index.html)
```

The site is plain static HTML, CSS and a little vanilla JavaScript generated by a small,
dependency-free Node script (`scripts/build.mjs`). It runs on any static host.

## Before going live

1. Fill in every `[TODO …]` value in [`src/config.mjs`](src/config.mjs) (company name, ЕИК, VAT
   number, addresses, managing director, hosting provider). `npm run placeholders` lists what is left.
2. Confirm the e-mail addresses, phone numbers and **prices** in the same file.
3. Choose how the forms are delivered: leave `formEndpoint` empty to open the visitor's e-mail program,
   or set `FORM_ENDPOINT` to an EU-hosted form handler covered by a data processing agreement
   (and name it in the privacy policy).
4. Have a lawyer review the legal texts in `src/pages/` (privacy, cookies, terms, legal notice,
   accessibility statement) against your actual processes.

## Compliance built in

| Area | What the site does |
| --- | --- |
| GDPR (Reg. 2016/679) | Privacy policy with all Art. 13/14 information, purposes/legal bases/retention table, rights-request form, КЗЛД complaint details; forms collect only what is needed and say why. |
| ePrivacy / ЗЕС чл. 4а | No tracking or analytics. The only optional item (OpenStreetMap) is blocked until opt-in; Accept and Reject are equally prominent; consent can be withdrawn from every page; choice expires after 12 months. |
| No third-party requests | No Google Fonts, CDNs, CAPTCHAs or pixels. Enforced by a strict Content-Security-Policy and by tests. |
| European Accessibility Act / WCAG 2.1 AA | Semantic HTML, skip link, keyboard support, visible focus, AA contrast, accessible forms and error summary, reduced-motion support, accessibility statement. axe-core runs on every page in CI. |
| Consumer protection (ЗЗП, Dir. 2011/83/EU) | Prices in euro with VAT treatment stated, terms with 14-day withdrawal right and model withdrawal form, complaints procedure, ADR via КЗП (the EU ODR platform closed in July 2025). |
| E-Commerce Act (ЗЕТ чл. 4) | Legal notice with company identity, ЕИК, VAT number, addresses and supervisory authorities. |
| ЗУЕС | Content reflects how a general meeting entrusts management to a professional manager under contract. |

## Deployment

`.github/workflows/deploy.yml` publishes to GitHub Pages on every push to `main` (enable Pages with
source "GitHub Actions"). Set the repository variable `SITE_URL` when using a custom domain.
For Netlify or Cloudflare Pages, use `npm run build` with `dist` as the output folder; the generated
`_headers` file adds HSTS, framing and other security headers.

## Structure

```
src/config.mjs       company details, prices, form endpoint
src/ui.mjs           shared interface strings (BG/EN)
src/layout.mjs       page shell: head, header, footer, consent banner
src/pages/*.mjs      one module per page, both languages
static/              CSS, JavaScript (consent manager, forms, menu), favicon
scripts/             build, local server, placeholder check
tests/               static checks and Playwright + axe browser tests
```
